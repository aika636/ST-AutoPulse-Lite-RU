# История изменений

## v2.1.6 (2026-10-14)

### 🔒 Безопасность

- **Серверный плагин: закрыт выход за пределы папки** в маршрутах `/jealousy-config/:charId`. Раньше запрос с `..%2F` в ID персонажа читал, перезаписывал или удалял любой `.json` в папке SillyTavern, включая `data/<пользователь>/secrets.json` с API-ключами. Теперь ID персонажа — только цифры, ID таймеров и задач — только `[A-Za-z0-9_-]`.
- **Серверный плагин: данные разделены по пользователям SillyTavern.** Таймеры, задачи, очередь событий и ключи API ревности хранятся в `plugins/autopulse/users/<пользователь>/`. Раньше они были общими на весь сервер: любой пользователь видел чужие ключи и мог создавать задачи, срабатывающие у других. Старые файлы при первом запуске переносятся в `users/default-user/`.
- **Серверный плагин: конфиг ревности сохраняет только известные поля** (endpoint, ключ, модель, max tokens, температура), а не произвольный JSON из запроса.
- **XSS через имя персонажа.** `escapeHtml` не экранировал кавычки, поэтому карточка с именем вида `x" onerror="…` выполняла JS во всплывашке ревности. Исправлено; также экранируются время и повтор задач, адреса аватаров.
- **Удалено отдельное приложение ChatPulse.** SillyTavern его не устанавливал, но его сервер слушал все сетевые интерфейсы без авторизации, разрешал CORS для любого сайта и отдавал API-ключи персонажей через `/api/characters`. Если вы запускали ChatPulse, смените ключи, которые в нём хранились.
- **Установщик:** можно указать конкретную версию через `AUTOPULSE_REF=<тег-или-коммит>`; после установки печатается SHA-256 плагина.

## v2.1.5 (2026-07-31)

### 🆕 Новые возможности

#### Отдельный API для автосообщений

- Автосообщения (по таймеру и реакция на возвращение) можно отправлять мимо пресета SillyTavern — как это уже умеет ревность.
- Контекст собирается с нуля: карточка персонажа + последние N сообщений + ваш промпт. Требования пресета к формату, длине и обязательным блокам перестают влиять на автосообщение.
- Настраивается в блоке автосообщений: endpoint (автодополняется до `/v1/chat/completions`), ключ, модель с загрузкой списка, макс. токенов, температура, глубина контекста.
- Выключено по умолчанию — без настройки генерация идёт через `generateQuietPrompt`, как раньше.

### 🆕 Прочее

- Ограничение длины автосообщения (`responseLength`) и regex-очистка автосообщений от RP-разметки.

### 🐛 Исправление ошибок

- Глубина контекста 0 больше не означает «передать всю историю» (`slice(-0)` возвращал весь массив). Затрагивало и ревность.

## v2.0.0 (2026-02-21)

### 🆕 Новые возможности

#### Система эмоционального давления 🧠

- Чем дольше персонаж ждёт вашего ответа, тем выше уровень давления (0–4).
- Чем выше давление, тем короче интервал между сообщениями (1.0x → 0.2x), в промпт добавляется тревожность.
- **Реакция на возвращение**: после вашего ответа персонаж реагирует в зависимости от времени ожидания:
  - Низкое давление → радость, успокоение 😊
  - Среднее давление → лёгкое недовольство, капризы 😐
  - Высокое давление → неудовлетворённость, гнев 😡
- Реакция на возвращение срабатывает только один раз, после чего давление сбрасывается до нуля.
- Все параметры настраиваются пользователем (максимальный уровень, включение / отключение реакции).
- Встроенные тестовые кнопки: давление +1, тестовый запуск, тест возвращения.

#### Плавающее окно ревности 💢

- При переключении чата оставленный персонаж может отправить уведомление с ревностью.
- Уведомление в виде плавающего окна с эффектом стекла в правом нижнем углу: аватарка + сообщение ревности.
- **Выбор персонажей**: можно указать, какие персонажи будут ревновать (не выбрано — не срабатывает).
- **Пользовательский промпт**: можно написать собственный промпт для управления стилем вывода.
- Настраиваемые параметры: вероятность срабатывания, минимальная / максимальная задержка.
- Автоматическая очистка от цепочек рассуждений, описаний действий и прочего мусора.
- Встроенная тестовая кнопка.

### 🐛 Исправление ошибок

#### Исправление фонового опроса

- Для опроса используется Web Worker вместо `setInterval`.
- Расширение больше не замораживается в фоновых вкладках браузера.
- При сбое Worker автоматически переключается на `setInterval`.

#### Совместимость с API SillyTavern

- Добавлен слой совместимости `callGenerateQuietPrompt`.
- Автоматическая адаптация под новую (объектные параметры) и старую (строковые параметры) версии API.
- Поддержка SillyTavern 1.12.0 ~ 1.16.0+.

### 📝 Документация

- Добавлена таблица для диагностики проблем (по содержимому логов F12).
